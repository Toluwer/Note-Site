Why Note

Designed as a system, not a pile of controls.

Every component shares the same theme, lifecycle, state, input, and overlay infrastructure, so the library stays predictable as interfaces grow.

Structured window system

Draggable and resizable windows, tabs, live search, collapsible sections, responsive clamping, minimize and restore behavior, and clean destruction.

Central theme binding

Surfaces, text, icons, borders, selections, and accent state update together through a shared theme manager.

Unified input handling

Mouse, touch, keybind capture, dragging, sliders, overlays, and outside-click dismissal share one managed input layer.

Shared overlay system

Dropdowns, color pickers, tooltips, notifications, and dialogs render above the window without being clipped.

Owned lifecycle

Connections, tweens, temporary effects, signals, overlays, and descendant resources are cancelled and cleaned predictably.

Component library

Everything needed for a complete interface.

Components expose consistent methods for visibility, disabled state, callbacks, values, flags, search matching, and destruction.

Installation

One file. One request. Ready to use.

The generated main.lua contains the complete module graph and returns a single Note library instance. No Rojo project, ReplicatedStorage package, RemoteEvent, or server script is required.

  • Client-side Luau
  • Lazy root initialization
  • Optional compatibility APIs
  • Deterministic generated distribution
main.lua 
local Note = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Toluwer/Note/main/main.lua"
))()

local Window = Note:CreateWindow({
    Title = "Note",
    Subtitle = "My Interface",
    Icon = "panel-left",
    Theme = "Dark",
    Size = UDim2.fromOffset(620, 450),
    Draggable = true,
    Resizable = true,
})
Architecture

Modular source, standalone delivery.

Development remains split into focused modules while the public build stays convenient for remote loading.

01

Modular source

Components, core services, internal helpers, and themes remain independently maintainable under src/.

02

Deterministic build

The bundler discovers the module graph, wraps modules in a cached loader, and verifies the result.

03

Single distribution

The committed main.lua decodes and executes the internal bundle without repository files at runtime.
